# 📌 About

ResumeCraft AI is a modern AI-powered Resume Builder that enables users to build professional, ATS-friendly resumes with beautiful templates, intelligent AI suggestions, customizable themes, and real-time resume preview.

> ⚠️ **Project Status:** This project is currently under active development. New AI features, backend services, authentication, database integration, and deployment are being added continuously.

# ✨ Features

- 🎯 AI ATS Score Analyzer
- 🤖 AI Grammar & Resume Improvement
- 🛡 Resume Authenticity Checker

- 📄 Professional Resume Templates
